# DPO_HSE_final-project_semantic.book.search

Используемые методы:
- Метод классификация модель логистическая регрессия (во входные данные идут вектора)
- Метод классификация модель логистическая регрессия (во входные данные идут эмбеддинги (frida-mini)
- Применение ранжирования
- Применение семантического поиска 

Итог: 
- необходимсть поработать над данными, очистить их от мусора
- семантический поиск иделаьно справляется с задачей
